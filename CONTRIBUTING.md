# Przewodnik dla Współtwórców / Contributing Guide

## 🇵🇱 Polski

### Pytania i Wsparcie

**Tak, możesz zadawać pytania do projektu!** Oto jak to zrobić:

1. **GitHub Issues** - Najlepsze miejsce na pytania
   - Przejdź do zakładki [Issues](../../issues)
   - Kliknij "New Issue"
   - Opisz swoje pytanie jasno i zwięźle
   - Dodaj etykietę "question" jeśli dostępna

2. **Dyskusje** - Dla ogólnych pytań
   - Sprawdź zakładkę [Discussions](../../discussions) jeśli jest dostępna
   - To świetne miejsce na pytania, które nie są błędami

### Zgłaszanie Błędów

Jeśli znalazłeś błąd:
1. Sprawdź czy błąd nie został już zgłoszony w [Issues](../../issues)
2. Utwórz nowe zgłoszenie z następującymi informacjami:
   - Opis problemu
   - Kroki do odtworzenia
   - Oczekiwane zachowanie
   - Aktualne zachowanie
   - Wersja Node-RED i używane węzły

### Propozycje Funkcjonalności

Masz pomysł na nową funkcję?
1. Otwórz nowe Issue z etykietą "enhancement"
2. Opisz funkcjonalność i jej zastosowanie
3. Wyjaśnij dlaczego byłaby przydatna

### Tworzenie Pull Requestów

1. Stwórz fork repozytorium
2. Utwórz nową gałąź dla swoich zmian
3. Wprowadź zmiany
4. Przetestuj zmiany w Node-RED
5. Zatwierdź zmiany z jasnym opisem
6. Utwórz Pull Request

### O Projekcie

OPEC-SIMPLE to projekt Node-RED do prostego sterowania siłownikiem. Używa:
- Node-RED Dashboard do interfejsu użytkownika
- Modbus do komunikacji
- Kontrola termostatu

## 🇬🇧 English

### Questions and Support

**Yes, you can ask questions about the project!** Here's how:

1. **GitHub Issues** - Best place for questions
   - Go to the [Issues](../../issues) tab
   - Click "New Issue"
   - Describe your question clearly and concisely
   - Add "question" label if available

2. **Discussions** - For general questions
   - Check the [Discussions](../../discussions) tab if available
   - Great place for questions that aren't bugs

### Reporting Bugs

If you found a bug:
1. Check if the bug hasn't already been reported in [Issues](../../issues)
2. Create a new issue with the following information:
   - Description of the problem
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Node-RED version and nodes used

### Feature Requests

Have an idea for a new feature?
1. Open a new Issue with "enhancement" label
2. Describe the functionality and its use case
3. Explain why it would be useful

### Creating Pull Requests

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes
4. Test changes in Node-RED
5. Commit changes with clear description
6. Create a Pull Request

### About the Project

OPEC-SIMPLE is a Node-RED project for simple actuator control. It uses:
- Node-RED Dashboard for user interface
- Modbus for communication
- Thermostat control
