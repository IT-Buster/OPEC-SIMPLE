OPEC-SIMPLE
===========

Proste sterowanie siłownikiem 

### O projekcie

Jest to projekt Node-RED do prostego sterowania siłownikiem z wykorzystaniem komunikacji Modbus.

### Funkcje

- Sterowanie termostatem
- Dashboard wizualizacyjny
- Manualna nastawa siłownika
- Obsługa protokołu Modbus

### Jak zadać pytanie

**Tak, możesz zadawać pytania dotyczące tego projektu!**

Aby zadać pytanie lub uzyskać pomoc:

1. **GitHub Issues** - Otwórz nowy issue na GitHub z etykietą "pytanie" lub "pomoc"
2. **GitHub Discussions** - Jeśli dostępne, użyj zakładki Discussions do dyskusji
3. Opisz swoje pytanie lub problem jak najdokładniej
4. Dołącz odpowiednie informacje (wersja Node-RED, system operacyjny, logi błędów itp.)

### Instalacja

1. Sklonuj repozytorium
2. Zainstaluj zależności: `npm install`
3. Uruchom Node-RED i zaimportuj przepływy z pliku `flows.json`

### Wymagania

- Node-RED
- Zależności wymienione w `package.json`
