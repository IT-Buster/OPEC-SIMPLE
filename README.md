OPEC-SIMPLE
===========

Proste sterowanie siłownikiem 

## 📋 O Projekcie / About

Projekt Node-RED do prostego sterowania siłownikiem z wykorzystaniem Modbus i interfejsu Dashboard.

This is a Node-RED project for simple actuator control using Modbus and Dashboard interface.

## 🚀 Instalacja / Installation

1. Zainstaluj Node-RED (jeśli jeszcze nie masz)
2. Sklonuj to repozytorium
3. Zainstaluj zależności:
   ```bash
   npm install
   ```
4. Uruchom Node-RED i wczytaj plik `flows.json`

## 📦 Zależności / Dependencies

- `@flowfuse/node-red-dashboard` - Dashboard UI
- `node-red-contrib-modbus` - Komunikacja Modbus
- `node-red-contrib-data-view` - Wizualizacja danych
- `node-red-dashboard` - Klasyczny dashboard
