# Jak współtworzyć projekt

Dziękujemy za zainteresowanie projektem OPEC-SIMPLE!

## Zadawanie pytań

**Tak, możesz zadawać pytania dotyczące tego projektu!**

### Gdzie zadać pytanie?

1. **GitHub Issues** - Najlepsza opcja do zadawania pytań technicznych
   - Otwórz nowy issue
   - Użyj tytułu zaczynającego się od "[Pytanie]"
   - Opisz swoje pytanie jak najdokładniej

2. **GitHub Discussions** - Do ogólnych dyskusji (jeśli dostępne)

### Jak zadać dobre pytanie?

Aby otrzymać najlepszą pomoc, uwzględnij następujące informacje:

- **Opisz problem** - Co próbujesz osiągnąć?
- **Co już próbowałeś** - Jakie kroki podjąłeś?
- **Środowisko** - Wersja Node-RED, system operacyjny
- **Logi błędów** - Jeśli występują błędy, dołącz komunikaty
- **Konfiguracja** - Informacje o Twoim urządzeniu Modbus (jeśli dotyczy)

### Przykład dobrego pytania

```
Tytuł: [Pytanie] Jak skonfigurować połączenie Modbus przez USB?

Treść:
Witam,
Próbuję połączyć się z urządzeniem Modbus przez USB (/dev/ttyUSB0), 
ale otrzymuję błąd połączenia.

Moja konfiguracja:
- Node-RED v3.0.2
- Ubuntu 22.04
- Prędkość transmisji: 115200

Komunikat błędu:
Error: EACCES: Permission denied, cannot access '/dev/ttyUSB0'

Co próbowałem:
- Sprawdziłem uprawnienia do /dev/ttyUSB0
- Przetestowałem inne prędkości transmisji

Czy ktoś może pomóc?
```

## Zgłaszanie błędów

Jeśli znalazłeś błąd:

1. Sprawdź, czy błąd nie został już zgłoszony
2. Otwórz nowy issue z etykietą "bug"
3. Opisz:
   - Kroki do odtworzenia błędu
   - Oczekiwane zachowanie
   - Rzeczywiste zachowanie
   - Wersje oprogramowania

## Sugerowanie ulepszeń

Masz pomysł na ulepszenie? Świetnie!

1. Otwórz nowy issue z etykietą "enhancement"
2. Opisz swoją propozycję
3. Wyjaśnij, dlaczego byłoby to przydatne

## Współtworzenie kodu

1. Sforkuj repozytorium
2. Stwórz nową gałąź dla swojej funkcji
3. Wprowadź zmiany
4. Przetestuj swoje zmiany
5. Wyślij Pull Request

## Licencja

Przesyłając swój wkład, zgadzasz się, że będzie on dostępny na tych samych warunkach co projekt.

## Dziękujemy!

Twoje pytania, sugestie i wkład sprawiają, że ten projekt jest lepszy!
